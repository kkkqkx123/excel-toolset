## B1 — `excel-sql/src/cache.rs` 借用检查错误 E0499

### 根因
`QueryCache::get()` 在一次 `match` 中对 `self.entries` 同时做了 `&self.entries.get_mut(key)`（可变借用）与后续 `self.entries.remove(key)` / `self.entries.get_mut(key)`（再次借用），借用作用域重叠，触发 `cannot borrow ... as mutable more than once at a time`。

### 修改方案（已应用，diff 来源 `build-fix.patch`）
将原"单次 match 内可变借用"拆成"先不可变判断过期 → 再可变操作"两段：

```rust
// 修改前（报错）
let now = Instant::now();
let ttl = Duration::from_secs(self.config.ttl_seconds);
if let Some(entry) = self.entries.get_mut(key) {
    if now.duration_since(entry.created_at) > ttl {
        self.entries.remove(key);
        return None;
    }
    entry.last_accessed = now;
    Some(&entry.result)
} else {
    None
}

// 修改后（正确）
let now = Instant::now();
let ttl = Duration::from_secs(self.config.ttl_seconds);
let expired = match self.entries.get(key) {
    Some(entry) => now.duration_since(entry.created_at) > ttl,
    None => return None,
};
if expired {
    self.entries.remove(key);
    return None;
}
let entry = self.entries.get_mut(key)?;
entry.last_accessed = now;
Some(&entry.result)
```

**语义不变**：过期则删并返回 `None`；命中则更新 `last_accessed` 并返回 `&result`。
**回归约束**：`tests` 模块（TTL / LRU / invalidate_file 等）必须仍全部通过。

## B2 — `excel-sql/src/converter/cell_convert.rs` 缺 `serde::Serialize`

### 根因
`QueryResult` 在 `query.rs` 中经 `ApiResponse` 序列化返回，但其 `#[derive]` 仅有 `Debug, Clone`，缺 `Serialize`，导致 `--features sql` 构建失败（E0277 `the trait bound QueryResult: Serialize is not satisfied`）。

### 修改方案（已应用）
```rust
// 修改前
#[derive(Debug, Clone)]
pub struct QueryResult { ... }

// 修改后
#[derive(Debug, Clone, serde::Serialize)]
pub struct QueryResult { ... }
```
（`serde` 已在 `excel-sql` 依赖中，仅需补 derive。）

## B3 — `excel-http/src/http/router.rs:59` axum 0.8 路由语法

### 根因
`Cargo.toml` 声明 `axum = "0.8"`（lock 0.8.9），但路由仍用 axum 0.7 的 `:id` 捕获语法。axum 0.8 在 `Router::route()` 阶段直接 panic：`Path segments must not start with ':'. For capture groups, use '{capture}'`。**这是 H1 的根因，二者同源。**

### 修改方案（已应用，同时消除 H1）
```rust
// 修改前
.route("/api/data/sql_session/:id", delete(sql::close_session))
// 修改后
.route("/api/data/sql_session/{id}", delete(sql::close_session))
```
